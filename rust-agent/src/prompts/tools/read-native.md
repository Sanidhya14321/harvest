Read UTF-8 workspace text or the shared notebook cell view. Positive one-based offset/limit select a contiguous window. Alternatively selector accepts N, N-M, N+K, N-, N..M, comma-separated ranges, -N tail, raw, or raw combined with ranges/tail. Ranges sort/merge; bare N reads from that line onward. A trailing path:selector is recognized only when the complete literal filename is confirmed absent. Literal colon-containing filenames and symlinks take precedence. Do not combine selector with offset/limit. Output is bounded; follow continuation offsets for oversized selections. Conflict/image/archive/URL/SSH-specific read surfaces remain under migration.
