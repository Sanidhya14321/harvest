Read text from the workspace with a [path#TAG] snapshot header and one-based numbered lines. Optional offset and limit select a line window. Reuse the exact returned path and tag in hashline edits. Only fully displayed numbered lines are authorized; read further windows before editing undisplayed lines. A continuation notice grants no additional line authority. Re-read after stale-tag errors or after resuming a session. Notebook reads use the shared editable cell projection. DOCX extraction is read-only and grants no edit authority.

Selectors accept N, N-M, N+K, N-, N..M, comma-separated ranges and -N tail, through selector or a trailing path:selector when no literal filename exists. Bare N reads from that line onward. Ranges sort/merge, and only complete displayed rows grant authority; gaps grant none. raw and raw:range return unnumbered text and grant no new seen-line authority. Do not combine selectors with offset/limit. Literal filenames, including symlinks, take precedence over attached selector interpretation.
