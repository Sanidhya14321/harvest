## [Unreleased]

### Added

- Preserve provider usage metadata and persist normalized token/cache counts; use `--request-usage` to request streamed accounting explicitly.

- Rename intact v3 sessions through native title slots while preserving all other session bytes.

- Recover interrupted v3 session tails to new files while preserving original data and reporting excluded bytes.

- Import legacy sessions to separate v3 files without overwriting existing data or discarding damaged records.

- Resume text and function-tool session-v3 branches with durable writes and ordered streaming JSON events.

- Inspect legacy and current session logs without rewriting their source.

- Added native project/user brain retrieval, evidence-based lesson admission, recoverable organization, restoration and explicit purge.
- Added a shared Rust library and both `harvest` and `omp` command aliases.

### Changed

- Repository credential checks now run through Rust tooling without the redundant Python scanner.

- Native edits preserve BOMs, line endings and notebook metadata through the shared Rust edit engine.

- Native builds include host-approved shell execution by default; use `--no-default-features --features core` for a lightweight build.
- Homebrew and WinGet release templates are generated by Rust workspace tooling.
- Require host approval for mutations and shell execution, with bounded file, session, HTTP and shell output.

### Fixed

- Reject explicitly unsuccessful JSON completions before committing assistant messages or executing their tools.

- Cancellation handles only abort their own run, and changed session files are rejected before appending.

- Help and version no longer install shell integration.
